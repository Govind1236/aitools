# Homepage Design Rules

## Hero Section
- Background: white (NOT gradient)
- Title: text-4xl md:text-5xl, font-weight 700, slate-900
- Subtitle: text-lg, slate-500, max-width 600px centered
- Search: large input (height 52px), full-width max-w-2xl, shadow-sm
- Stats row: text-sm, slate-400, separated by dots

## Categories Grid
- 5 columns on desktop, 3 on tablet, 2 on mobile
- Cards: white bg, border slate-200, padding 20px, text-center
- Icon: 32px Lucide icon, slate-600
- Name: text-sm, font-medium, slate-900
- Count: text-xs, slate-400

## Tool Sections
- Section titles: text-2xl, font-bold, slate-900
- Subtitles: text-sm, slate-500
- "View all" link: text-sm, blue-600, right-aligned
- Cards: 3 columns desktop, 2 tablet, 1 mobile

## CTA Section
- Background: slate-900
- Text: white
- Button: white bg, slate-900 text
